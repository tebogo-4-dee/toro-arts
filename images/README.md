# Images folder — Toro Arts Music Academy

Every placeholder graphic in this folder marks a spot in the site where a real
photo, video thumbnail, or the logo should go. Replace a placeholder by
swapping in a real file with the **same filename** (or update the `src` in
the HTML if you use a different name/format — .jpg and .png both work fine).
